Spotify GitHub Profile

Available routes

  • /api/loginSign in with Spotify and get your uid.
  • /api/callbackOAuth callback used by Spotify after login. Not meant to be opened directly.
  • /api/view?uid=YOUR_UIDNow-playing card as HTML. Options: theme, cover_image, bar_color, background_color, mode, border_radius, show_offline, hide_remaster.
  • /api/view.svg?uid=YOUR_UIDSame card as SVG, for use in a README image.
